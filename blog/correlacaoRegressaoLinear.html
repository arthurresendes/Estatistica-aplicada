Correlação e Regressão Linear - Exercício

Aqui vamos descobrir se duas variáveis andam juntas e usar essa relação para fazer previsões.

Conceitos

  • Variável x (independente): a que usamos para explicar ou prever. Neste exercício, o ano.
  • Variável y (dependente): a que queremos prever. Neste exercício, a produção.
  • Diagrama de dispersão: um gráfico em que cada ponto é um par (x, y). Ele mostra se existe relação entre as variáveis.
  • Coeficiente de correlação (r): um número entre −1 e 1 que mede a força da relação linear. Perto de 1: quando x aumenta, y aumenta (correlação positiva forte). Perto de −1: quando x aumenta, y diminui (correlação negativa forte). Perto de 0: não há relação linear.
  • Reta ajustada (regressão linear): a reta que melhor passa pelos pontos, escrita como ŷ(x) = ax + b. Com ela, estimamos y para qualquer x.
  • Interpolação e extrapolação: estimar um valor dentro do intervalo dos dados é interpolar. Estimar fora dele é extrapolar, e quanto mais longe, menos confiável.

Exercício

2. A tabela abaixo apresenta a produção de uma indústria:

Anos (x'i) 198019811982198319841985198619871988
Quantidades (t) (yi) 343636384142434446

Determine:

  1. Construa o diagrama de dispersão.
  2. O coeficiente de correlação.
  3. A reta ajustada.
  4. A produção estimada para 1979.

a - Diagrama de dispersão

Os pontos sobem da esquerda para a direita, o que indica que a produção cresce com os anos.

b - Coeficiente de correlação

2 passo - Aplicar a fórmula

Fórmula:

r = (n · Σ(xiyi) − Σxi · Σyi) / √((n · Σxi2 − (Σxi)2) · (n · Σyi2 − (Σyi)2))

Dados da tabela: n = 9, Σxi = 17856, Σyi = 360, Σxiyi = 714330, Σxi2 = 35426364 e Σyi2 = 14538

r = (9 · 714330 − 17856 · 360) / √((9 · 35426364 − (17856)2) · (9 · 14538 − (360)2))

r = (6428970 − 6428160) / √((318837276 − 318836736) · (130842 − 129600))

r = 810 / √(540 · 1242)

r = 810 / √670680

r = 810 / 818,95

r ≈ 0,9891

Como r está muito perto de 1, existe uma correlação positiva muito forte entre o ano e a produção.

c - Reta ajustada

Fórmula:

ŷ(x) = ax + b

O a (coeficiente angular) diz quanto y muda quando x aumenta 1. O b (coeficiente linear) é o valor de ŷ quando x = 0.

Cálculo do a:

a = (n · Σ(xiyi) − Σxi · Σyi) / (n · Σxi2 − (Σxi)2)

a = (9 · 714330 − 17856 · 360) / (9 · 35426364 − (17856)2)

a = (6428970 − 6428160) / (318837276 − 318836736)

a = 810 / 540

a = 1,5

Cálculo do b:

b = Σyi/n − a · Σxi/n

b = 360/9 − 1,5 · 17856/9

b = 40 − 1,5 · 1984

b = 40 − 2976

b = −2936

ŷ(x) = 1,5x − 2936

O a = 1,5 significa que, a cada ano, a produção aumenta em média 1,5 tonelada. O b é um número grande e negativo porque x = 0 seria o ano 0, muito longe dos dados, e não tem significado prático.

d - Produção estimada para 1979

Como não simplificamos, usamos o ano cheio (x = 1979):

ŷ(1979) = 1,5 · 1979 − 2936

ŷ(1979) = 2968,5 − 2936

ŷ(1979) = 32,5

Como 1979 está fora do intervalo dos dados (1980 a 1988), essa estimativa é uma extrapolação.

Dica: simplificando as contas

Números grandes como 3920400 são fáceis de errar. Para evitar, podemos usar uma variável auxiliar, subtraindo um ano de referência de todos os anos: x = x' − 1984.

Assim os valores de x ficam −4, −3, ..., 0, ..., 3, 4, e as contas ficam bem menores. O resultado de r e o valor de a não mudam; só o b muda:

ŷ(x) = 1,5x + 40, com x = ano − 1984

Para 1979, x = 1979 − 1984 = −5, então ŷ = 1,5 · (−5) + 40 = 32,5, o mesmo valor de antes.

Lembre: se a reta foi montada com x simplificado, o ano também precisa ser simplificado antes de substituir.
