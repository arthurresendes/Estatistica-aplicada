Distribuição Normal

A distribuição normal é uma distribuição de probabilidade contínua, representada por uma curva em formato de sino. Ela é definida pela média (μ) e pelo desvio-padrão (σ).

Para resolver exercícios envolvendo essa distribuição, utilizamos a padronização dos valores, transformando-os em escores Z. Dessa forma, conseguimos consultar a tabela da distribuição normal padrão.

1. Fórmula da padronização

A fórmula utilizada para encontrar o valor de Z é:

Z = (X - μ) / σ

  • X: valor que queremos analisar.
  • μ: média da distribuição.
  • σ: desvio-padrão.
  • Z: valor padronizado.

2. Como interpretar a tabela Z

A tabela utilizada neste conteúdo apresenta a área entre a média (Z = 0) e um determinado valor positivo de Z. Portanto, ela não apresenta diretamente a probabilidade acumulada à esquerda.

Para consultar um valor, utilizamos a linha correspondente à primeira casa decimal e a coluna correspondente à segunda casa decimal.

Por exemplo, para Z = 1,96, consultamos a linha 1,9 e a coluna 0,06. O resultado encontrado é aproximadamente 0,475002.

Regras para utilizar a tabela

  • Z positivo: a área entre a média e o valor positivo é consultada diretamente na tabela.
  • Z negativo: utilizamos a simetria da curva normal para consultar o valor positivo correspondente.
  • Intervalo que atravessa a média: somamos as duas áreas encontradas na tabela.
  • Intervalo do mesmo lado da média: subtraímos a menor área da maior área.
  • Probabilidade de cauda: subtraímos a área encontrada de 0,5, quando queremos uma das extremidades.

3. Exercício resolvido

Um banco mede o tempo de atendimento de seus clientes no caixa. O tempo se distribui normalmente, com média de 20 minutos e desvio-padrão de 5 minutos.

Dados do exercício:

  • Média: μ = 20 minutos.
  • Desvio-padrão: σ = 5 minutos.

a) Qual é a probabilidade de um atendimento durar entre 15 e 30 minutos?

1º passo: padronizar os dois valores.

Para X = 15:

Z = (15 - 20) / 5 = -1,00

Para X = 30:

Z = (30 - 20) / 5 = 2,00

2º passo: consultar a tabela.

  • Z = 1,00 → área = 0,341345.
  • Z = 2,00 → área = 0,477250.

Como o intervalo vai de um valor negativo para um positivo, atravessando a média, devemos somar as duas áreas.

P(-1,00 < Z < 2,00) = 0,341345 + 0,477250

P(-1,00 < Z < 2,00) = 0,818595

Resposta: aproximadamente 81,86%.

b) Qual é a probabilidade de um atendimento durar entre 25 e 32,5 minutos?

1º passo: padronizar os valores.

Para X = 25:

Z = (25 - 20) / 5 = 1,00

Para X = 32,5:

Z = (32,5 - 20) / 5 = 2,50

2º passo: consultar a tabela.

  • Z = 1,00 → área = 0,341345.
  • Z = 2,50 → área = 0,493790.

Como os dois valores estão do mesmo lado da média, devemos subtrair a menor área da maior.

P(1,00 < Z < 2,50) = 0,493790 - 0,341345

P(1,00 < Z < 2,50) = 0,152445

Resposta: aproximadamente 15,24%.

c) Qual é a probabilidade de um atendimento durar menos de 12 minutos?

1º passo: padronizar o valor.

Z = (12 - 20) / 5 = -1,60

2º passo: consultar a tabela.

Como a tabela apresenta valores positivos, utilizamos a simetria da distribuição normal e consultamos Z = 1,60.

Z = 1,60 → área = 0,445201.

3º passo: encontrar a área à esquerda.

A área total à esquerda da média corresponde a 0,5. Portanto, subtraímos a área encontrada na tabela.

P(Z < -1,60) = 0,5 - 0,445201

P(Z < -1,60) = 0,054799

Resposta: aproximadamente 5,48%.

d) O banco quer premiar os 2,5% dos atendimentos mais rápidos. Qual é o tempo máximo de atendimento para entrar nesse grupo?

Neste item, precisamos encontrar o tempo correspondente aos 2,5% menores valores da distribuição.

1º passo: interpretar a probabilidade.

Os 2,5% mais rápidos representam a área à esquerda do valor procurado:

P(Z < z) = 0,025

Como a tabela apresenta a área entre a média e um valor positivo, calculamos:

0,5 - 0,025 = 0,475

2º passo: localizar o valor na tabela.

Procuramos o valor mais próximo de 0,475 na tabela. Encontramos 0,475002, correspondente a Z = 1,96.

Como estamos procurando os 2,5% da extremidade esquerda, utilizamos Z = -1,96.

3º passo: retornar ao valor original.

Utilizamos a fórmula da padronização isolando X:

X = μ + Z × σ

X = 20 + (-1,96 × 5)

X = 20 - 9,8

X = 10,2 minutos

Resposta: o tempo máximo de atendimento para entrar no grupo dos 2,5% mais rápidos é de aproximadamente 10,2 minutos.

4. Resumo dos resultados

Item Probabilidade ou resultado
a) 81,86%
b) 15,24%
c) 5,48%
d) 10,2 minutos
