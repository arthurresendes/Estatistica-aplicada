Variáveis Aleatórias

Uma variável aleatória (X) associa um número a cada resultado de um experimento aleatório. Por exemplo, ao lançar 2 moedas, X pode ser o número de caras (0, 1 ou 2).

Ela é discreta quando assume valores que podem ser contados (0, 1, 2...) e contínua quando pode assumir qualquer valor de um intervalo. Esta página trata das discretas.

Neste material usamos: p = probabilidade de sucesso e q = probabilidade de fracasso, com q = 1 − p.

Distribuição de probabilidade

É a tabela que mostra cada valor possível de X e a sua probabilidade P(X). A soma de todos os P(X) é sempre 1.

Exemplo: número de caras em 2 lançamentos de uma moeda.

Probabilidade de um intervalo

Soma-se o P(X) de cada valor incluído.

P(X > 0) = P(X = 1) + P(X = 2) = 2/4 + 1/4 = 3/4

Esperança E(X)

O valor médio esperado de X, a média ponderada pelas probabilidades. Se repetíssemos o experimento muitas vezes, seria o valor médio obtido.

E(X) = Σ(X · P(X))

E(X) = 0 + 2/4 + 2/4 = 1

Variância VAR(X)

Mede o quanto os valores de X se espalham em torno da esperança.

VAR(X) = E(X2) − (E(X))2, onde E(X2) = Σ(X2 · P(X))

VAR(X) = 1,5 − (1)2 = 0,5

Desvio-padrão (σ)

A raiz da variância, na mesma unidade de X.

σ = √VAR(X)

σ = √0,5 ≈ 0,7071

Propriedades

Sendo a e b constantes:

E(aX ± b) = a · E(X) ± b

VAR(aX ± b) = a2 · VAR(X)

Somar ou subtrair uma constante muda a média, mas não muda a variância. Multiplicar por a multiplica a média por a e a variância por a2.

Bernoulli

Um experimento com uma única tentativa e apenas dois resultados possíveis: sucesso (X = 1) ou fracasso (X = 0). Exemplo: lançar uma moeda uma vez e ver se saiu cara.

P(X = k) = pk · q1−k, com k = 0 ou k = 1

E(X) = p

VAR(X) = p · q

q = 1 − p

Exemplo: moeda justa, com p = 1/2 e q = 1/2. Então E(X) = 1/2 e VAR(X) = 1/2 · 1/2 = 1/4.

P(X = 1) = 0,2

Para k = 0:

P(X = 0) = (0,2)0 · (0,8)1

P(X = 0) = 1 · 0,8

P(X = 0) = 0,8

Binomial

O número de sucessos em n tentativas independentes, todas com a mesma probabilidade de sucesso p. É a soma de n variáveis de Bernoulli. Exemplo: número de caras em 10 lançamentos.

P(X = k) = C(n, k) · pk · qn−k, com k = 0, 1, ..., n

Onde C(n, k) = n! / (k! · (n − k)!) é o número de combinações, ou seja, de quantas formas k sucessos podem aparecer em n tentativas.

E(X) = n · p

VAR(X) = n · p · q

q = 1 − p

O exemplo da tabela acima é uma binomial com n = 2 e p = 1/2: E(X) = 2 · 1/2 = 1 e VAR(X) = 2 · 1/2 · 1/2 = 0,5.

Exemplo resolvido: probabilidade de sair exatamente 2 caras em 3 lançamentos (n = 3, p = 1/2, k = 2):

P(X = 2) = C(3, 2) · (1/2)2 · (1/2)1 = 3 · 1/4 · 1/2 = 3/8

Exercício - Binomial

2. Uma prova tem 5 questões de múltipla escolha, cada uma com 4 alternativas e só uma correta. Um aluno não estudou e responde todas ao acaso. Seja X o número de questões que ele acerta.

  1. Quais são os valores de n, p e q?
  2. Qual é a probabilidade de acertar exatamente 2 questões?
  3. Qual é a probabilidade de não acertar nenhuma?
  4. Qual é a probabilidade de acertar pelo menos 1 questão?
  5. Determine E(X) e VAR(X).

a -

n é o número de tentativas, que são as 5 questões: n = 5

O sucesso é acertar a questão. Há 1 alternativa correta entre 4:

p = 1/4

q = 1 − p

q = 1 − 1/4

q = 3/4

b -

Fórmula:

P(X = k) = C(n, k) · pk · qn−k

Dados: n = 5, k = 2, p = 1/4 e q = 3/4

P(X = 2) = C(5, 2) · (1/4)2 · (3/4)3

C(5, 2) = 5! / (2! · 3!) = 10

P(X = 2) = 10 · (1/16) · (27/64)

P(X = 2) = 270 / 1024

P(X = 2) ≈ 0,2637

c -

Dados: k = 0

P(X = 0) = C(5, 0) · (1/4)0 · (3/4)5

P(X = 0) = 1 · 1 · (243/1024)

P(X = 0) ≈ 0,2373

d -

"Pelo menos 1" é tudo, menos nenhum acerto:

P(X ≥ 1) = 1 − P(X = 0)

P(X ≥ 1) = 1 − 0,2373

P(X ≥ 1) ≈ 0,7627

e -

Fórmulas:

E(X) = n · p

E(X) = 5 · 1/4

E(X) = 5/4 = 1,25

VAR(X) = n · p · q

VAR(X) = 5 · 1/4 · 3/4

VAR(X) = 15/16 = 0,9375

Poisson

O número de ocorrências de um evento em um intervalo de tempo (ou espaço), quando os eventos são raros, acontecem de forma independente e a uma taxa média constante. Exemplo: número de ligações recebidas por hora.

P(X = k) = (e−λ · λk) / k!, com k = 0, 1, 2, ...

Onde λ é a média de ocorrências no intervalo e e ≈ 2,71828.

E(X) = λ

VAR(X) = λ

Na Poisson, a esperança e a variância são iguais.

Exemplo resolvido: uma central recebe em média 2 ligações por hora (λ = 2). A probabilidade de não receber nenhuma em uma hora é:

P(X = 0) = (e−2 · 20) / 0! = e−2 ≈ 0,1353

Exercício - Poisson

3. Uma central de atendimento recebe, em média, 3 ligações por minuto. Seja X o número de ligações recebidas em um minuto. Use e−3 ≈ 0,0498.

  1. Qual é o valor de λ?
  2. Qual é a probabilidade de não receber nenhuma ligação em um minuto?
  3. Qual é a probabilidade de receber exatamente 2 ligações em um minuto?
  4. Qual é a probabilidade de receber pelo menos 1 ligação em um minuto?
  5. Determine E(X) e VAR(X).
  6. Qual é a probabilidade de receber pelo menos 2 ligações em 5 minutos? Use e−15 ≈ 0,000000306.

a -

O λ é a média de ocorrências no intervalo da pergunta. Como a média é de 3 ligações por minuto e a pergunta é sobre 1 minuto:

λ = 3

b -

Fórmula:

P(X = k) = (e−λ · λk) / k!

Dados: λ = 3 e k = 0

P(X = 0) = (e−3 · 30) / 0!

P(X = 0) = (e−3 · 1) / 1

P(X = 0) = e−3 ≈ 0,0498

c -

Dados: λ = 3 e k = 2

P(X = 2) = (e−3 · 32) / 2!

P(X = 2) = (0,0498 · 9) / 2

P(X = 2) = 0,4482 / 2

P(X = 2) ≈ 0,2241

d -

"Pelo menos 1" é tudo, menos nenhuma ligação:

P(X ≥ 1) = 1 − P(X = 0)

P(X ≥ 1) = 1 − 0,0498

P(X ≥ 1) ≈ 0,9502

e -

Na Poisson, a esperança e a variância são iguais ao λ:

E(X) = λ = 3

VAR(X) = λ = 3

f -

Agora o intervalo mudou para 5 minutos, então o λ também muda. Achamos o novo λ com uma regra de três:

Tempo (minutos) Ligações (média)
13
5x

x = (5 · 3) / 1

λ = 15

"Pelo menos 2" é tudo, menos 0 e 1 ligação:

P(X ≥ 2) = 1 − P(X = 0) − P(X = 1)

Para k = 0:

P(X = 0) = (e−15 · 150) / 0!

P(X = 0) = e−15 ≈ 0,0000003

Para k = 1:

P(X = 1) = (e−15 · 151) / 1!

P(X = 1) = 0,000000306 · 15

P(X = 1) ≈ 0,0000046

P(X ≥ 2) = 1 − 0,0000003 − 0,0000046

P(X ≥ 2) ≈ 0,999995

Como esperamos 15 ligações em 5 minutos, é quase certo que cheguem pelo menos 2.
